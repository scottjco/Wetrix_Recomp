Wetrix Recompiled 0.1.0 comparison captures

Captured from the running Windows build in its windowed mode using the supported
Wetrix ROM. The PNGs are direct window captures, including the window title.
No game artwork was painted into these screenshots and no image upscaling was
applied to them. Window capture dimensions are 1442 x 810 pixels.

title-native-original.png: HD Textures Off, Aspect Ratio 4:3.
title-native-expand.png:   HD Textures Off, Aspect Ratio Expand.
title-hd-original.png:     HD Textures On, Aspect Ratio 4:3.
title-hd-expand.png:       HD Textures On, Aspect Ratio Expand.

All four show the Classic menu, with Hybrid FPS Mode and Display frame-rate
target. They were captured separately. The platter, reflections, rings, logo,
and native color transitions animate, so their phases differ between images.
The optional HD setting also restores the original platter geometry when Off.

Screenshot capture settings and keyboard device selection were temporary;
personal settings were backed up for restoration and are not distributed.

Gameplay captures added 2026-11-03:
classic-hd-expand.png: native Classic mode 1.
challenge-hd-expand.png: native Challenge mode 64 (first challenge).
practice-hd-expand.png: native Practice mode 128 (Raised Land B).

HD Textures On, Aspect Ratio Expand, Original FPS mode (30 FPS). A local-only
capture build invokes each original menu callback, rotates and holds native
drop until water is present, allows one second of flow, then stops simulation.
The spill container is kept empty at each native write, without clearing the
water on the board. No water is painted into the gameplay screenshots. Original FPS mode avoids retaining interpolation history
when freezing a still frame. The rejected duplicate-arrow Practice capture
was withdrawn and is not used in the gallery.

Images are direct window captures exported as PNG, without painting terrain,
water, scores or artwork into the image. Capture hooks and temporary device
preferences are not part of the release executable or committed game source.
The capture build uses a separate working folder and save, preserving personal
saves and settings. No Press Start or high-score screen is used in this gallery.
