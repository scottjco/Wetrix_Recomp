# Controls and settings

Run Wetrix.cmd starts the game directly. Escape opens or closes the same
RecompFrontend settings overlay used by Silicon Valley. Controller Back/Share
opens the menu. General, Graphics, Controls, and Sound tabs are available.

Default keyboard controls: WASD moves, Space drops, E rotates, Enter starts.
Q is Z, R is R, and arrow keys are the C buttons. Controller south/Cross drops,
east/Circle rotates, and Start/Options starts. Bindings can be changed in Controls.
Settings are saved under config/user; the controller pak is saves/controller1.mpk.

Graphics supports resolution, downsampling, window mode, and interpolated
framerate. Display follows the current monitor; Manual permits targets up to
240 FPS, capped by the monitor refresh rate. Original disables interpolation.
Game logic remains 30 FPS in every mode. The title reports rendered frames.
Unsupported graphics options and the launcher/mod browser are not shown.

The initial window is centered and sized to 75% of the monitor under the mouse.
Sound controls the master output volume. Controller pak data is preserved on exit.
