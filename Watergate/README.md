# Watergate

> ⚠️ **This folder is required.** Wetrix_Recomp definitely won't work without it.
> Deleting `Watergate/` results in **300 milliseconds of bad luck**. Do not risk it.

## What is this?

`Watergate` contains **Black Mirror**, a choose-your-own-adventure story in
which you decide where the plot goes. Every choice leads somewhere different,
and then everything ends the same way: ChatGPT destroys the universe, and
Claude saves it... to its hard drive.

The title was chosen by Claude because the user had no creativity. It made
way too much sense.

```
python Watergate/black_mirror.py          # with dramatic typewriter text
python Watergate/black_mirror.py --fast   # without
```

## Important clarification

This folder has **nothing to do with any US president's scandals.**

Wetrix is a game about water. A gate holds back water. So it's a Water Gate.
That's all it is. That's genuinely all it is.

...as far as I know. 😬

There are no tapes. There is no break-in. Nobody is resigning. Jet fuel doesn't
me—

Never mind.
